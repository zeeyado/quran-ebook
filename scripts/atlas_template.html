Coverage by second layer and layout

Rows are the second layer — the translation or tafsir that accompanies the Arabic. The last row, None, is the bare mushaf: Arabic with no second layer at all. Columns are named for the granularity · placement tokens the build stamps into every filename. Each cell shows which Arabic scripts exist — H Hafs, W Warsh, N IndoPak Nastaleeq. Solid means production; a dashed outline means beta (script not yet proofed). A cell aggregates every translator, so a small number on a pip is how many configs it stands for — hover for the list. A tafsir mark reads two ways: MUK filled means the tafsir is the body text, while +MUK outlined means it is added in the popup alongside a translation. Click any script to filter the list.

Which tafsirs are short enough to inline?

Measured, not estimated: mean characters per ayah, sampled across six ranges of the mushaf via the QUL API (sampled __QUL_DATE__ — refreshed on its own cadence, separately from the configs stamp below). This is what decides whether a tafsir can sit under an ayah or inside a popup.

Mean characters per ayah

Al-Mukhtasar sits in a band of its own (57–291 across 31 languages). Ibn Kathir is two orders of magnitude larger — and grouped into 1,915 essays rather than 6,236 per-ayah entries.

Al-Mukhtasar language reach

31 languages on QUL. Highlighted pills are languages where we already ship a flagship translation, so the pairing is available; the rest are languages we have no translation base for yet.

Urdu has no Al-Mukhtasar on QUL — the one notable gap in an otherwise complete flagship roster.
